# mypost

> **专为个人打造的纯本地 API 调试与管理工具**  
> 纯净单机应用，**无需登录、无需外网**，项目与接口数据全量以**标准 JSON 文件**保存在本地磁盘。

---

## 🎯 设计初衷与核心理念

现代许多 API 工具逐渐转向强制云端同步、强制登录账号、团队订阅等繁重模式，不仅需要联网，还伴随着个人私有接口与 Token 泄露的隐私顾虑。

**mypost** 的核心定位是一款**完全属于个人本地**的高颜值、高性能 API 调试工作台：
- **纯净单机使用**：打开即用，无需注册登录，没有广告，无需连接任何远程服务器，即便在完全离线或机密内网环境下也能流畅工作。
- **数据本地文件保存**：所有数据（项目、分组、接口、环境变量）均以**标准明文 JSON 文件**存储在本机目录中。不使用私有黑盒数据库，数据完全归你所有，随时可直接复制备份、版本比对或直接纳入个人 Git 仓库管理。
- **全协议通信支持**：深度支持 HTTP/HTTPS、SSE 流式事件监听与 WebSocket 全双工长连接，自带内存保护机制，应对复杂接口游刃有余。

---

## 🌟 核心功能特性

### 1. 纯本地 JSON 数据管理
- **透明的目录结构**：项目数据以独立的 JSON 文件组织，结构清晰直观：
  - `project.json`：项目基本信息
  - `tree.json`：树形目录与接口节点层级关系
  - `envs.json`：环境变量与全局变量
  - `apis/{api_id}.json`：各个接口的完整请求与响应配置
- **极简备份与迁移**：复制项目文件夹即可完成全量备份或迁移到新电脑，亦可直接放入 Git 仓库进行个人提交与历史回溯。
- **多格式导入导出**：支持一键导入 cURL 命令、Swagger/OpenAPI (JSON/YAML) 以及 Postman 集合文件，支持将接口导出为标准 Markdown 文档。

### 2. HTTP / HTTPS 接口调试
- **常用与扩展方法**：完整覆盖 GET、POST、PUT、DELETE、PATCH 等 HTTP 请求。
- **多样化参数配置**：
  - Query / Path 路由参数
  - 请求头 Headers、Cookie 管理
  - 请求体 Body：`none`、`form-data`、`x-www-form-urlencoded`、`json`、`raw`（文本/XML）、`binary`（二进制文件上传）
- **通用鉴权方式**：原生支持 Bearer Token、Basic Auth、API Key（Header / Query 参数注入）。
- **脚本与测试断言**：内置轻量沙箱，支持前置预处理脚本（Pre-request Script）与后置测试断言（Tests），自动校验接口返回状态与字段。
- **实际请求抓包追踪**：内置“实际请求”查看面板，清晰查看经网络引擎重定向、变量计算、Headers 补全后真正发给服务器的底层原始报文。

### 3. SSE (Server-Sent Events) 流式推送调试
- **双视图自由切换**：支持**美化卡片视图**（JSON 高亮、事件类型筛选、折叠/展开）与**原始报文视图**（标准 Wire 协议 `event:` / `data:` / `id:`）无缝切换。
- **防卡死流控机制**：针对持续推送的数据流，内置环形缓冲区与 FIFO 淘汰机制（支持自定义 200/500/1000/2000 上限），结合帧率合并调度，防止海量事件导致渲染卡死。
- **多标签后台保持**：切换标签页不会断开已建立的流式连接，后台持续监听，只有主动关闭标签页时才断开。

### 4. WebSocket 全双工通信调试
- **协议兼容**：支持 `ws://` 与 `wss://` 连接协议，支持配置连接参数、自定义 Headers 与子协议（`Sec-WebSocket-Protocol`）。
- **可拖拽分屏工作台**：握手配置区与消息发送区支持上下平滑拖拽调整高度，双击快速重置比例。
- **定时心跳保活**：支持配置 Heartbeat Ping 自动保活包与周期间隔，配置自动持久化保存。
- **数据流监控与搜索**：收发双向消息色彩区分，支持按消息方向筛选、按关键词搜索、文本/JSON 美化格式化以及快捷键发送（`Ctrl+Enter`）。
- **缓冲保护与帧序号保持**：配备高频消息微批次合并与缓冲区上限管理，即便早期历史被修剪，累计统计与帧序号（`#seq`）依然连续准确。

### 5. 动态变量占位符系统 (`{{variable}}`)
- **全域支持**：URL 地址、Query 参数、Headers、Auth 鉴权、Body 以及长连接地址中均支持 `{{variable}}` 动态插值。
- **智能联想气泡**：输入 `{{` 自动触发环境变量与全局变量候选菜单，支持键盘快速选择。
- **悬停即时预览**：鼠标悬停在变量胶囊上即可实时查看变量当前求值与归属来源（环境变量 / 全局变量）。
- **支持嵌套解析**：变量间支持层级引用（例如 `{{baseUrl}}` 引用 `{{domain}}`）。

## ⌨️ 常用快捷键

| 快捷键 | 功能说明 |
| :--- | :--- |
| **`Ctrl + Enter`** | 发送当前 HTTP 请求 / 发送当前 WebSocket 消息 |
| **`Ctrl + S`** | 保存当前接口配置修改（直接写入本地 JSON 文件） |
| **`Ctrl + W`** | 关闭当前标签页（自动断开关联的 SSE / WebSocket 连接） |

## 📂 本地数据存储结构

mypost 存储的项目完全由清晰的本地文件构成：

```
~/.mypost/projects/<project_id>/   （或你指定的任意本地目录）
├── project.json                   # 项目基本信息 (名称、描述、创建时间)
├── tree.json                      # 接口树形层级结构 (目录与接口映射关系)
├── envs.json                      # 环境变量组与全局变量列表
└── apis/                          # 接口明文配置目录
    ├── api-1729178000000.json     # 单个接口详细配置 (URL、Headers、Body、Auth等)
    └── api-1729178000001.json
```

> **提示**：你可以随时直接用文本编辑器（如 VS Code）查看或编辑这些 `.json` 文件，也可以将整个目录初始化为 Git 仓库进行个人版本追踪。

## 🛠️ 本地开发与构建

### 1. 环境准备
- Node.js >= 24
- npm >= 9

### 2. 启动开发模式
```bash
# 安装依赖
npm install

# 启动开发服务器与本地客户端
npm run dev
```

### 3. 运行自动化测试
```bash
# 运行单元测试套件 (包含文件存储、网络引擎、长连接等验证)
npm test
```

### 4. 打包本地客户端
```bash
# 构建 Windows 安装包与免安装便携版
npm run package:win

# 构建 macOS DMG 镜像
npm run package:mac

# 构建 Linux AppImage 与 DEB 安装包
npm run package:linux
```
构建产物将输出在 `release/` 目录下。

## 🔒 隐私与安全声明

- **零数据上报**：本应用不包含任何遥测（Telemetry）、用户分析打点或追踪代码。
- **100% 数据归属本地**：你的所有请求地址、私有 API Token、Cookie 以及测试数据，仅且只会存储在你的本机硬盘中。
- **离线安全**：在完全断开互联网的环境下，全部核心功能正常可用。
